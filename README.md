# piechartstudios.com

The studio page for Piechart Studios: one page listing each project with its link.

- Published with GitHub Pages from the root of the `main` branch, at https://piechartstudios.com (see `CNAME`).
- To add a project, copy one `<li class="project">` block in `index.html` and add its icon next to it.
- Each project's own site lives at `<project>.piechartstudios.com` and is built in that project's repository.
